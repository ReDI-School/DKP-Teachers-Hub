# 👩‍🌾 RANGERS

**Rangers** is our Bridge "Brücke" of our Sunday Class, designed for children aged **11-13**. This course is entirely there to support **the transition from block-based programming in the Heroes class to text-based programming in the Superheroes class.** Using EduBlocks the children can gradually make the step from block-based programming to text-based programming, while refreshing their coding knowledge from the Heroes class in order to be **perfectly prepared for the Superheroes class.**
